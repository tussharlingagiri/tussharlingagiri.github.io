## Phase 1: Immediate Actions (May–August 2026)

### Priority 1: Ship Minimal FPGA Accelerator (8–12 weeks)
**Goal:** Move from "interested in FPGAs" to "built and benchmarked FPGA accelerator"  
**Quant Angle:** Frame this for **trading infrastructure** relevance, not just AI/ML

#### Project Scope: INT8 CNN Accelerator (with Trading Context)
**Target:** 3×3 convolution accelerator on Zynq/Artix-7 FPGA  
**Framing for Quant Roles:** "Sub-millisecond inference engine for real-time pattern recognition in market data"

**Deliverables:**
- [ ] SystemVerilog RTL for 3×3 convolution engine
- [ ] Cocotb or UVM testbench with 95%+ coverage
- [ ] Synthesized bitstream with timing closure
- [ ] Benchmark report: latency, throughput, resource utilization (LUTs, DSPs, BRAM)
- [ ] Comparison: FPGA vs. CPU vs. GPU inference time
- [ ] GitHub repo with full documentation

**Why This Project:**
- Simple enough to complete in 8–12 weeks
- Demonstrates RTL design, verification, synthesis, and benchmarking
- Shows understanding of compute vs. memory bottlenecks
- Provides concrete numbers for resume/interviews

**Technical Milestones:**
1. **Week 1-2:** Implement 3×3 convolution in SystemVerilog, simulate with test vectors
2. **Week 3-4:** Build testbench (Cocotb), verify correctness with random inputs
3. **Week 5-6:** Synthesize for target FPGA, optimize for timing closure
4. **Week 7-8:** Benchmark on real hardware, generate performance report
5. **Week 9-10:** Compare with TensorFlow/PyTorch CPU/GPU baseline
6. **Week 11-12:** Document, create demo video, publish to GitHub

**Success Metrics:**
- Achieve <1ms inference latency for single layer
- Resource utilization <50% of target FPGA
- Fmax ≥ 100 MHz
- <2% accuracy loss vs. floating-point baseline

## Interview Preparation: Expected Questions

### Technical Deep Dive Questions

**FPGA & Hardware:**
1. "Walk me through the critical path of your FPGA inference pipeline. Where's the bottleneck?"
   - *Prep:* Know exact critical path from synthesis report, explain memory vs. compute bottlenecks

2. "How do you handle memory bandwidth limitations in FPGA accelerators?"
   - *Prep:* Discuss on-chip buffering, data reuse, tiling strategies

3. "Explain your verification methodology. How do you ensure correctness?"
   - *Prep:* Walk through testbench architecture, coverage metrics, corner cases

4. "What's the difference between Fmax, throughput, and latency in your design?"
   - *Prep:* Be ready to explain clock frequency vs. pipeline stages vs. end-to-end latency

**AI/ML Systems:**
5. "Your multi-agent system—how do you handle agent failures? What's your latency budget?"
   - *Prep:* Discuss fault tolerance, timeout strategies, async communication

6. "Explain quantization-aware training. Why does it matter for FPGA deployment?"
   - *Prep:* Walk through QAT process, calibration, precision-performance tradeoffs

7. "If I give you a Zynq UltraScale+ and a BERT model, what's your 2-week plan?"
   - *Prep:* Outline: profile model → identify bottlenecks → quantize → implement critical ops in RTL → integrate with PS → benchmark

**Systems Design:**
8. "Design a low-latency inference service for a trading system. What are the key constraints?"
   - *Prep:* Discuss tail latency, determinism, fault tolerance, monitoring

9. "How would you debug a performance regression in your FPGA accelerator?"
   - *Prep:* Walk through methodology: profile → isolate → hypothesis → test → fix

**Quantitative Finance (if applicable):**
10. "How would you use FPGAs for options pricing or risk calculation?"
    - *Prep:* Research Monte Carlo acceleration, Black-Scholes on FPGAs, low-latency market data processing
